## 一、项目介绍

本工作区是湖南桥桥友河智能装备有限责任公司的企业官网与产品 3D 展厅前端。

项目核心由两部分组成：

1. **企业官网**——首页 `/` 与关于页 `/about`，以六段单线叙事呈现企业制造现场、业务能力、团队与区位；采用实拍视频 Hero、沉浸轮播与工业编辑式排版。
2. **望衡 HENGVIEW 3D 展厅**——独立路由 `/hengview`，基于 Three.js 的装配开机叙事页：工业展厅、真实顶升机构运动、舵轮转向、断层透察 X-ray、DARK/LIGHT 主题切换与滚动分镜编排。

站点无接口层、无 CMS、无后端服务，采用 `nuxt generate` 纯静态输出，可部署到任意静态托管、对象存储 + CDN 或自有 nginx。

### 当前页面

| 路由          | 内容                     | 源码入口                  |
| ----------- | ---------------------- | --------------------- |
| `/`         | 企业官网首页、制造现场与业务概览       | `pages/index.vue`     |
| `/about`    | 企业档案单屏卡：沉浸轮播 + 档案与商务联系 | `pages/about.vue`     |
| `/hengview` | 望衡 HENGVIEW 机器人 3D 展厅  | `pages/hengview.vue`  |
| 其他路径        | HTTP 404 页面            | `pages/[...slug].vue` |

共享导航、公司资料和业务范围统一维护在 `data/site-content.ts`，不在页面组件中维护第二份公司信息。

## 四、开发环境

### 环境要求

- **操作系统**：Windows 11（也支持 macOS / Linux，命令适配即可）

> 仓库只使用 `pnpm-lock.yaml`，不要混用 npm、yarn 或生成第二份锁文件。

### 安装依赖

```powershell
Set-Location E:\0zero\desktop\桥桥友河企业官网前端\Front
pnpm install --frozen-lockfile
```

更换机器或首次安装时保留 `--frozen-lockfile`，确保安装结果与锁文件一致。

## 五、如何构建预览

以下命令均在 `Front/` 目录下执行。

### 开发服务器

```powershell
pnpm dev --host=127.0.0.1
```

默认地址 `http://127.0.0.1:3000/`。若 Nuxt CLI 将分开的 host 参数误解析为项目根目录，使用等号形式 `--host=127.0.0.1`。

### 静态检查

```powershell
pnpm typecheck         # Nuxt / Vue TypeScript 类型检查
pnpm verify:hengview   # HENGVIEW 页面、场景模块、模型、文档与包配置结构检查（29 项）
```

### 生产构建与预览

```powershell
pnpm build             # 生成 Nuxt Node 生产产物到 .output/
pnpm preview --host=127.0.0.1  # 本地启动生产产物，默认端口 3000
```

### 静态站点输出（临时上线采用）

```powershell
pnpm generate          # 纯静态站点输出到 .output/public/
```

### 静态产物预演

```powershell
pnpm dlx serve .output/public
```

> 使用 `pnpm dlx` 保持仓库的 pnpm 约束；不要使用 `npx` 或引入第二个包管理器。

### 验收说明

项目当前没有独立的单元测试或 lint 脚本。生产构建通过后仍需用真实浏览器检查 `/`、`/about`、`/hengview` 和 404，并覆盖桌面与移动视口（推荐 1280x720 / 1440x900 桌面与 390x844 移动端）。3D 展厅还需确认：

- Canvas 非空，模型加载完成
- 加载层正常退出
- 滚动分镜依次推进
- DARK / LIGHT 主题切换可用
- 返回官网入口可点击
- `prefers-reduced-motion` 下内容完整可读
- 浏览器控制台无页面脚本错误

### HENGVIEW 调试入口

- 慢放开机时间线：`/hengview?slowboot`（开机放慢 3 倍，供视觉检查）
- 开发模式下场景实例挂载到 `window.__hengviewScene`，仅供只读诊断；生产构建不应依赖该句柄。

## 七、HENGVIEW 3D 展厅说明

`/hengview` 是望衡 HENGVIEW 机器人 3D 展厅的唯一正式入口，包含装配开机叙事、滚动镜头、真实顶升机构、舵轮转向、断层透察 X-ray 与 DARK/LIGHT 展厅切换。

### 机械语义

- GLB 原始姿态是 2.0M 最高工作位，滚动机构向内套叠收拢。
- `mzz01-mechanism-profile.ts` 中 `middle.travel = 0.26`、`top.travel = 0.92` 表示向下收回下一节内部的距离。
- 摄像头总成、长导杆和顶节附件具有不同随动规则，不能凭视觉猜测节点与运动方向。
- HUD 米制数值表示当前工作高度：最高位 `2.00M`，最大收拢位 `0.00M`。

### 代码入口

- `pages/hengview.vue`：正式页面状态、加载层、滚动叙事、HUD、CTA、主题切换及生命周期管理。
- `lib/hengview/hengview-scene.ts`：Three.js 场景内核、模型加载、开机时间线、镜头分镜、机构运动、展厅、灯光、粒子、地面、画质治理和资源释放。
- `lib/hengview/hengview-materials.ts`：材质分级、扫描物化、全息和 X-ray Shader 注入。
- `lib/hengview/hengview-post.ts`：后处理、Bloom、暗角、颗粒和蓝噪声治理。
- `data/mzz01-mechanism-profile.ts`：顶升机构行程与节点配置。
