## 困难点 3：IMU 物理轴校准到 ROS2 标准坐标系

### 核心挑战

加速度是矢量，陀螺仪是角速度，四元数是整体姿态 — 三者物理意义不同，校准方式不同

### 解决方案

**3.1 加速度：轴映射 + 符号（完整使用 axis_mapping）**

cpp

```
// 加速度是矢量，符号表示方向
msg.linear_acceleration.x = mapAxis(accel_raw, front_idx, front_sign);
msg.linear_acceleration.y = mapAxis(accel_raw, left_idx, left_sign);
msg.linear_acceleration.z = mapAxis(accel_raw, up_idx, up_sign);
```



text

```
配置: front: "y", left: "-x", up: "z"
物理 y → ROS2 x, 物理 -x → ROS2 y, 物理 z → ROS2 z
车头向下: x 正增大 ✅，左侧抬起: y 正增大 ✅
```



**3.2 陀螺仪：只交换轴，不乘符号（findAxisSignInMapping）**

cpp

```
// 陀螺仪是角速度，符号由右手定则决定，与 left: "-x" 的负号无关
float gyro_x_mapped = findAxisSignInMapping("x") * mapAxis(gyro_raw, front_idx, front_sign);
float gyro_y_mapped = findAxisSignInMapping("y") * mapAxis(gyro_raw, left_idx, left_sign);
float gyro_z_mapped = findAxisSignInMapping("z") * mapAxis(gyro_raw, up_idx, up_sign);

float findAxisSignInMapping(target) {
    // 只提取轴对应的符号，不直接用 left_sign
    // 例如 left: "-x" → 对 X 轴返回 -1.0
    //     front: "y" → 对 Y 轴返回 1.0
}
```



text

```
抬头: y 为正 ✅，左转: z 为正 ✅，左侧抬起: x 为正 ✅
```

**3.4 四元数零点校准（最关键）**

cpp

```
// 原理：静止时记录初始姿态，后续只输出相对变化量
// 类比：北京出发往南走100公里到保定，增量正确但起点在北京
//       零点校准 = 把起点设为北京

if (gyro_magnitude < stationary_threshold) {
    stationary_counter_++;
    if (stationary_counter_ >= 50) {  // 连续静止 0.5 秒
        is_stationary_ = true;
    }
}

if (is_stationary_ && !initial_quat_set_) {
    initial_quat_ = quat_;  // 记录参考零点
    initial_quat_set_ = true;
}

// 输出相对四元数（减去初始偏置）
Eigen::Quaternionf relative_quat = initial_quat_.inverse() * quat_;
```



text

```
静止时: (1, 0, 0, 0) ✅，抬头: pitch 为正 ✅，左倾: roll 为正 ✅
```



**3.5 ENU vs NED 适配**

cpp

```
// quaternionToEuler 保持 ROS2 ENU 标准（加负号）
euler.y() = -asin(2*(w*y - z*x));  // ENU: 抬头为正，取反
euler.x() = -atan2(2*(w*x + y*z), 1 - 2*(x²+y²));

// attitude_compensator 根据测试调整补偿符号
comp_x = -sin(pitch) * gravity_strength;  // 车头抬起 → 向前补偿
```



**3.6 验证标准**

| 检查项   | ROS2 标准             | 验证方法                                                |
| :------- | :-------------------- | :------------------------------------------------------ |
| 加速度   | 水平 z=9.8，前倾 x 正 | `ros2 topic echo /imu/data --field linear_acceleration` |
| 角速度   | 抬头 y 正，左转 z 正  | `ros2 topic echo /imu/data --field angular_velocity`    |
| 四元数   | 静止时 (1,0,0,0)      | `ros2 topic echo /imu/data --field orientation`         |
| 姿态补偿 | 车头抬起向前补偿      | `ros2 topic echo /cmd_vel_compensated --field linear`   |

## 关键设计原则

| 原则                     | 说明                                      |
| :----------------------- | :---------------------------------------- |
| **加速度是矢量**         | 完整使用 axis_mapping 的符号              |
| **陀螺仪是角速度**       | 只交换轴，符号由右手定则决定              |
| **四元数是整体**         | 零点校准把静止姿态设为参考原点            |
| **坐标系在接口层统一**   | axis_mapping 只在 imu_dri 中处理一次      |
| **方向在补偿层测试验证** | attitude_compensator 根据物理测试调整符号 |
