# 坐标轴映射校准

编译调试

```
sudo docker start -ai cerebellum

colcon build --symlink-install

source install/setup.bash

ros2 launch bringup dri_bringup.launch.py

ros2 launch bringup algorithms_bringup.launch.py

ros2 topic echo /imu/data_raw --field linear_acceleration
ros2 topic echo /imu/data --field linear_acceleration

ros2 topic echo /imu/data_raw --field angular_velocity
ros2 topic echo /imu/data --field angular_velocity

ros2 topic echo /imu/data --field orientation
```

ros2标准: 前方为+x、后方为-x、左侧为+y、右侧为-y、上方为+z、下方为-z

加速度计原始输出与姿态的对照表，加速度输出符号与重力相反，朝天为+，朝地为-

| 姿态                | 轴朝向 | X轴    | Y轴    | Z轴    |
| :------------------ | :----- | :----- | :----- | :----- |
| 水平静止0°          | Z+朝天 | 0      | 0      | **+g** |
| 倒立180°            | Z+朝地 | 0      | 0      | **-g** |
| 抬头90°             | X+朝天 | **+g** | 0      | 0      |
| 低头90°             | X+朝地 | **-g** | 0      | 0      |
| 左倾90°（左侧下压） | Y+朝地 | 0      | **-g** | 0      |
| 右倾90°（右侧下压） | Y+朝天 | 0      | **+g** | 0      |

```
轴映射
ROS 2标准轴		IMU物理轴			 IMU物理轴	
front		  变化最大轴*期望g输出  -accel_y * +g = -y
left		  变化最大轴*期望g输出  -accel_x * -g = +x
up		      变化最大轴*期望g输出  +accel_z * +g = +z
```

# 角速度轴映射校准

基本上角速度方向和加速度方向是一致的

| 旋转动作                  | 理论值 (ωx, ωy, ωz) |
| :------------------------ | :------------------ |
| 右滚转（右侧下压 Y+指天） | (+, 0, 0)           |
| 左滚转（左侧下压 Y+指地） | (-, 0, 0)           |
| 抬头（前方抬起）          | (0, +, 0)           |
| 低头（前方下压）          | (0, -, 0)           |
| 左转（逆时针）            | (0, 0, +)           |
| 右转（顺时针）            | (0, 0, -)           |
